# 到点换壁纸

一款专为上班族设计的 Android 壁纸切换应用。上班时一键切换为工作壁纸，下班后一键恢复个人壁纸，让你的工作生活更有仪式感。

## 功能特性

- 🎯 **一键切换**：点击应用图标即可切换壁纸，无需复杂操作
- ⚡ **快速访问**：长按应用图标弹出快捷菜单，直接进入设置界面
- 🖼️ **壁纸备份**：自动备份当前壁纸，随时可恢复
- ⚙️ **灵活配置**：支持自定义延迟退出时间（5-10秒）
- 🔒 **安全可靠**：所有壁纸存储在应用私有目录，不会泄露

## 使用场景

- **上班时**：打开应用，自动切换为工作壁纸
- **下班后**：再次打开应用，恢复为个人壁纸
- **会议中**：快速切换为专业壁纸，提升职业形象

## 技术特点

- **兼容性强**：支持 Android 7.0 (API 24) 及以上版本
- **MIUI/HyperOS 适配**：针对小米系统深度优化，解决权限问题
- **Android 16 支持**：兼容最新 Android 版本的权限变更
- **轻量级**：安装包小，运行流畅，不占用系统资源

3. 首次运行需要授予存储权限

## 使用方法

### 基本使用

1. **设置工作壁纸**
   - 打开应用，点击"选择工作壁纸"
   - 从相册选择一张适合作为工作壁纸的图片
   - 应用会自动备份当前壁纸

2. **切换壁纸**
   - **上班时**：点击应用图标，自动切换为工作壁纸
   - **下班后**：再次点击应用图标，自动恢复为个人壁纸

3. **快速设置**
   - 长按应用图标，选择"设置"直接进入设置界面

### 高级功能

- **手动设置壁纸**：在设置界面点击"手动设置工作壁纸"
- **手动恢复壁纸**：在设置界面点击"手动恢复原壁纸"
- **删除备份**：在设置界面点击"删除备份"（谨慎操作）

## 权限说明

应用需要以下权限才能正常工作：

- **存储权限**：用于读取和保存壁纸图片
- **壁纸设置权限**：用于修改系统壁纸

所有权限仅用于壁纸切换功能，不会收集或上传任何个人数据。

## 常见问题

### Q: 为什么需要存储权限？
A: 应用需要读取你选择的壁纸图片，并备份当前壁纸。所有文件都存储在应用私有目录，不会访问其他应用的数据。

### Q: 壁纸切换失败怎么办？
A: 请检查是否授予了存储权限。如果问题持续，可以尝试在设置中删除备份后重新设置。

### Q: 支持动态壁纸吗？
A: 目前仅支持静态壁纸（图片）。动态壁纸切换功能计划在后续版本中添加。

### Q: 如何完全卸载应用？
A: 卸载应用会自动删除所有备份和设置。如果需要保留备份，请先手动导出。
